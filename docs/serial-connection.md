# 串口连接与排查

MineBottom 在 Windows 客户端读取绑定拉杆的通电状态，通过 CH340 串口发送开关指令。LCUS-1 继电器随即接通或切断小夜灯的 5V 供电。多人服务器只负责照常同步方块状态，USB 操作在玩家自己的电脑上完成。

## 1. 接线

准备一块 CH340 串口型 LCUS-1 单路继电器、一个取电 USB 公头、一个插灯用 USB 母头和三根导线。灯应是普通 5V USB 供电，并在重新供电时自动亮。先用直插电脑的方式确认灯正常。

拔掉两个 USB 公头再接线。螺丝端子夹住裸铜，按实物标识接线。公头和母头的端子顺序可能不同。

```text
电脑 USB 口 1 → LCUS-1 自带 USB 公头（模块供电、接收指令）

电脑 USB 口 2 → 取电公头
  V+ ─── 继电器 COM
         继电器 NO ─── 灯侧 USB 母头 V+
   - ──────────────── 灯侧 USB 母头 -
                       灯插入 USB 母头
```

继电器的 COM/NO 是常开触点。吸合时闭合，灯的正极接通。放开时断开。灯的负极直接连回取电公头。NC、D+、D− 留空，接线只涉及 USB 低压侧。

## 2. 驱动与 COM 口

1. 安装 [沁恒 CH340/CH341 Windows 驱动](https://www.wch.cn/downloads/CH341SER_EXE.html)。
2. 将继电器板的 USB 公头插到电脑，打开设备管理器 → **端口（COM 和 LPT）**，查找 `USB-SERIAL CH340 (COMx)`。可通过拔插模块确认哪一项对应继电器。
3. COM7 只是示例，换 USB 口后编号可能变化。模组自动匹配已连接的 `VID_1A86&PID_7523` 设备，并使用 Windows 分配的 COM 号。如果找到多个匹配端口，它会提示只保留继电器。
4. 串口由模组独占。用过串口调试工具或旧 Python 桥接后，先退出这些程序再启动模组的控制功能。

## 3. 串口参数和指令

使用 **9600 bps、8 数据位、无校验、1 停止位（8N1）**，关闭硬件及软件流控。下面每行都是四个原始十六进制字节。串口工具要选择 HEX 发送，关闭自动加换行。

| 动作 | 字节 | 结果 |
| --- | --- | --- |
| 开灯 | `A0 01 01 A2` | 第一路继电器吸合，COM 和 NO 导通 |
| 关灯 | `A0 01 00 A1` | 第一路继电器释放，COM 和 NO 断开 |

帧依次为起始字节、通道号、动作和校验。校验是前三个字节求和后取低 8 位。其他外观相近的 USB 模块可能采用不同协议，请核对所购版说明。[LCUS-1 协议与串口调试示例](https://smartqat.com/products/lcus-1-plc-usb-serial-control-relay-module)

调试时可先只插控制板，用串口工具发送开灯和关灯帧，观察继电器状态灯或听是否吸合和释放。确认触点动作后，拔电接上灯的供电线路，再测实物亮灭。

## 4. 游戏内验证

启动装有模组和匹配 Fabric API 的客户端，进入存档或服务器。没有绑定时，可手动输入 `/nightlight test on` 和 `/nightlight test off`。对准原版拉杆输入 `/nightlight bind` 后，由拉杆接管。输入 `/nightlight status` 查看绑定坐标、拉杆状态和最近的串口结果。

模组首次打开串口先发关闭帧。后台串口线程合并快速拨动，连续切换之间至少间隔 500 毫秒。退出存档、断开连接或绑定位置离开客户端已加载区块时，模组尝试关灯。串口故障时，仍需要控制或关灯的情况下会间隔约 2 秒重试。串口写入成功只能确认电脑发出了指令，灯的实际状态需要看实物。

## 5. 常见问题

| 现象 | 先检查 |
| --- | --- |
| 设备管理器只有 USB Serial，提示代码 28 | 安装 CH340 驱动，重新插拔继电器板。 |
| 游戏提示找不到 CH340 | 确认设备的硬件 ID 符合上方 VID/PID，且使用继电器板自带公头连接电脑。 |
| 已找到 COM 口，但无法打开 | 关闭串口助手、旧桥接以及其他正在控制继电器的游戏实例。 |
| 继电器响，灯不亮 | 检查灯是否能直插点亮、两端 GND 是否直连，以及正极是否经过 COM/NO。断电后可绕过继电器，将两个 V+ 和两个 GND 分别直连，定位供电问题。 |
| 串口工具能控制，但拨杆没反应 | 用 `/nightlight status` 检查是否绑定了当前服务器、维度和坐标，以及绑定区块是否已加载。 |
